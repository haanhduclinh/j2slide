# j2slide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Cloudflare Workers service where an AI agent pushes chart JSON over HTTP or MCP and the slide appears immediately on every open viewer.

**Architecture:** A Hono Worker validates requests against Zod schemas and forwards them to one Durable Object per deck. The Durable Object is the only store — it holds the deck's slides, the SHA-256 of its API key, and the hibernatable WebSockets of every viewer, so a push is one write plus a fan-out with no lookup table on the path. The viewer is dependency-free vanilla JS that renders each slide type to SVG through pure functions.

**Tech Stack:** TypeScript, Cloudflare Workers, Durable Objects (SQLite-backed, WebSocket Hibernation API), Hono, `@hono/zod-openapi`, `@hono/swagger-ui`, Vitest with `@cloudflare/vitest-pool-workers`.

**Spec:** `docs/superpowers/specs/2026-08-02-j2slide-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

- **Language:** All code, comments, identifiers, commit messages and docs are in English.
- **Platform:** Cloudflare Workers Paid plan. `compatibility_date` is `2026-07-01` for both `wrangler.jsonc` and the Vitest miniflare config — they must always match.
- **Durable Objects:** SQLite-backed (`new_sqlite_classes`). One DO class only: `DeckDO`. One DO instance per deck, named by `deck_id`.
- **No external network in the viewer:** no CDN, no web fonts, no charting library. The viewer must work on a locked-down network.
- **Renderers are pure:** every function in `public/render.js` takes data and returns an SVG string. No DOM access, no `document`, no side effects. This is what makes them testable.
- **Zod import rule:** always `import { z } from "@hono/zod-openapi"`, never from `zod` directly. The re-export is version-matched to the OpenAPI generator; importing `zod` separately can pull a second, incompatible copy.
- **Limit values** (verbatim from spec §4, defined once in `src/limits.ts`): title ≤ 80 chars; body ≤ 32 KB; bar/line 1–12 points with label ≤ 24 chars and unit ≤ 8 chars; pie 1–8 slices with value ≥ 0; text 1–8 bullets each ≤ 120 chars; kpi 1–4 items with label ≤ 24, value ≤ 12, delta ≤ 10.
- **Deck limits:** 200 slides per deck (evict oldest), 60 slides per minute (token bucket), 7-day inactivity expiry that deletes slides but keeps `meta`.
- **Identifiers:** `deck_id` = 32 hex chars from `crypto.getRandomValues`. `api_key` = `sk_` + 32 hex chars. Never MD5. Only the SHA-256 digest of the key is stored.
- **Commit after every task.** Commit messages use Conventional Commits.

## File Structure

| File | Responsibility |
|---|---|
| `src/limits.ts` | Numeric limit constants. Single source of truth for Zod, MCP JSON Schema and the DO. |
| `src/schemas.ts` | Zod slide schemas built from `limits.ts`. Drives validation and OpenAPI. |
| `src/mcp-schemas.ts` | Hand-built JSON Schema for MCP tools, built from `limits.ts`. |
| `src/auth.ts` | Key generation, SHA-256 hashing, constant-time compare, Bearer parsing. |
| `src/deck-do.ts` | `DeckDO`: storage, seq allocation, eviction, rate limit, alarm, WebSocket broadcast. |
| `src/deck-stub.ts` | Resolves a `deck_id` to its DO stub. One function, so no route hand-rolls DO addressing. |
| `src/errors.ts` | Maps a `DeckErrorCode` to an HTTP status and response body. |
| `src/routes/decks.ts` | REST: create deck, push slide, list slides, clear slides. |
| `src/routes/viewer.ts` | Viewer HTML shell and the WebSocket upgrade route. |
| `src/routes/mcp.ts` | MCP Streamable HTTP endpoint wrapping the same handlers. |
| `src/index.ts` | App assembly, OpenAPI document, Swagger UI, `DeckDO` export. |
| `public/theme.js` | Palette and typography tokens. |
| `public/render.js` | Pure `renderSlide` plus one renderer per slide type. |
| `public/viewer.js` | WebSocket client, deck navigation, keyboard, reconnect. |
| `public/viewer.css` | Page chrome, letterboxing, transitions, theme variables. |

`render.js` stays free of DOM access so its output can be asserted directly; `viewer.js` owns all DOM and socket state. That split is the reason the chart code is testable at all.

```ts
import { z } from "@hono/zod-openapi";
import { L } from "./limits";

const title = z.string().min(1).max(L.TITLE_MAX).openapi({ example: "Revenue by quarter" });

// `.finite()` is not available across all Zod majors; refine instead so the
// schema behaves identically no matter which version resolves.
const finite = z.number().refine((n) => Number.isFinite(n), {
  message: "value must be a finite number",
});

const label = z.string().min(1).max(L.LABEL_MAX);

const Point = z.object({ label, value: finite }).openapi("Point");
const PieSlice = z.object({
  label,
  value: finite.refine((n) => n >= 0, { message: "value must not be negative" }),
}).openapi("PieSlice");

export const BarSlide = z.object({
  type: z.literal("bar"),
  title,
  unit: z.string().max(L.UNIT_MAX).optional().openapi({ example: "M USD" }),
  data: z.array(Point).min(1).max(L.SERIES_MAX),
}).openapi("BarSlide");

export const LineSlide = z.object({
  type: z.literal("line"),
  title,
  unit: z.string().max(L.UNIT_MAX).optional(),
  data: z.array(Point).min(1).max(L.SERIES_MAX),
}).openapi("LineSlide");

export const PieSlide = z.object({
  type: z.literal("pie"),
  title,
  data: z.array(PieSlice).min(1).max(L.PIE_MAX),
}).openapi("PieSlide");

export const TextSlide = z.object({
  type: z.literal("text"),
  title,
  bullets: z.array(z.string().min(1).max(L.BULLET_MAX)).min(1).max(L.BULLETS_MAX),
}).openapi("TextSlide");

export const KpiSlide = z.object({
  type: z.literal("kpi"),
  title,
  items: z.array(z.object({
    label,
    value: z.string().min(1).max(L.KPI_VALUE_MAX).openapi({ example: "12.4M" }),
    delta: z.string().max(L.KPI_DELTA_MAX).optional().openapi({ example: "34%" }),
    trend: z.enum(["up", "down", "flat"]).optional(),
  })).min(1).max(L.KPI_MAX),
}).openapi("KpiSlide");

export const SlideInput = z.discriminatedUnion("type", [
  BarSlide, LineSlide, PieSlide, TextSlide, KpiSlide,
]);

export type SlideInput = z.infer<typeof SlideInput>;

/** A slide as stored and broadcast: the validated input plus deck-assigned fields. */
export type Slide = SlideInput & { seq: number; createdAt: number };
```

- [ ] **Step 3: Write `src/auth.ts`**

```ts
const HEX = "0123456789abcdef";

function toHex(bytes: Uint8Array): string {
  let out = "";
  for (const b of bytes) out += HEX[b >> 4] + HEX[b & 0x0f];
  return out;
}

function randomHex(byteLength: number): string {
  const buf = new Uint8Array(byteLength);
  crypto.getRandomValues(buf);
  return toHex(buf);
}

/**
 * 32 hex characters drawn from a CSPRNG. The shape matches an MD5 digest, but
 * the bytes are random rather than derived — a hash of guessable input would
 * make the id guessable.
 */
export function generateDeckId(): string {
  return randomHex(16);
}

export function generateApiKey(): string {
  return `sk_${randomHex(16)}`;
}

export async function hashKey(key: string): Promise<string> {
  const digest = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(key));
  return toHex(new Uint8Array(digest));
}

/** Constant-time for equal-length inputs; length inequality is not secret here. */
export function timingSafeEqual(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  let diff = 0;
  for (let i = 0; i < a.length; i++) diff |= a.charCodeAt(i) ^ b.charCodeAt(i);
  return diff === 0;
}

export function extractBearer(header: string | null | undefined): string | null {
  if (!header) return null;
  const match = /^Bearer\s+(\S+)$/.exec(header);
  return match ? match[1] : null;
}
```

```ts
import { DurableObject } from "cloudflare:workers";
import { timingSafeEqual, hashKey } from "./auth";
import { L } from "./limits";
import type { Slide, SlideInput } from "./schemas";

export type DeckErrorCode = "deck_not_found" | "forbidden" | "rate_limited";

export type DeckResult<T> =
  | { ok: true; value: T }
  | { ok: false; error: DeckErrorCode; retryAfter?: number };

interface DeckMeta {
  apiKeyHash: string;
  createdAt: number;
  lastActiveAt: number;
  /** Next seq to hand out. Monotonic for the deck's whole life. */
  nextSeq: number;
  /** Seq of the oldest slide still stored. */
  firstSeq: number;
  count: number;
}

const META = "meta";
const slideKey = (seq: number) => `slide:${String(seq).padStart(6, "0")}`;

export class DeckDO extends DurableObject<unknown> {
  /** Creates the deck. Idempotent: re-initialising an existing deck is a no-op. */
  async init(apiKeyHash: string): Promise<void> {
    const existing = await this.ctx.storage.get<DeckMeta>(META);
    if (existing) return;

    const now = Date.now();
    const meta: DeckMeta = {
      apiKeyHash,
      createdAt: now,
      lastActiveAt: now,
      nextSeq: 1,
      firstSeq: 1,
      count: 0,
    };
    await this.ctx.storage.put(META, meta);
  }

  /** Public: lets the viewer route 404 an unknown deck without holding a key. */
  async exists(): Promise<boolean> {
    return (await this.ctx.storage.get<DeckMeta>(META)) !== undefined;
  }

  async pushSlide(
    apiKey: string,
    input: SlideInput,
  ): Promise<DeckResult<{ seq: number; index: number; total: number }>> {
    const auth = await this.authorize(apiKey);
    if (!auth.ok) return auth;
    const meta = auth.value;

    const seq = meta.nextSeq;
    const slide: Slide = { ...input, seq, createdAt: Date.now() };

    await this.ctx.storage.put(slideKey(seq), slide);
    meta.nextSeq = seq + 1;
    meta.count += 1;

    while (meta.count > L.SLIDE_CAP) {
      await this.ctx.storage.delete(slideKey(meta.firstSeq));
      meta.firstSeq += 1;
      meta.count -= 1;
    }

    meta.lastActiveAt = Date.now();
    await this.ctx.storage.put(META, meta);

    return { ok: true, value: { seq, index: meta.count - 1, total: meta.count } };
  }

  async listSlides(apiKey: string): Promise<DeckResult<{ slides: Slide[]; total: number }>> {
    const auth = await this.authorize(apiKey);
    if (!auth.ok) return auth;

    const slides = await this.readSlides();
    return { ok: true, value: { slides, total: slides.length } };
  }

  async clearSlides(apiKey: string): Promise<DeckResult<{ cleared: number }>> {
    const auth = await this.authorize(apiKey);
    if (!auth.ok) return auth;
    const meta = auth.value;

    const cleared = await this.deleteAllSlides(meta);
    meta.lastActiveAt = Date.now();
    await this.ctx.storage.put(META, meta);

    return { ok: true, value: { cleared } };
  }

  protected async authorize(apiKey: string): Promise<DeckResult<DeckMeta>> {
    const meta = await this.ctx.storage.get<DeckMeta>(META);
    if (!meta) return { ok: false, error: "deck_not_found" };

    const presented = await hashKey(apiKey);
    if (!timingSafeEqual(presented, meta.apiKeyHash)) {
      return { ok: false, error: "forbidden" };
    }
    return { ok: true, value: meta };
  }

  protected async readSlides(): Promise<Slide[]> {
    const stored = await this.ctx.storage.list<Slide>({ prefix: "slide:" });
    // Zero-padded keys sort lexicographically in seq order.
    return [...stored.values()];
  }

  protected async deleteAllSlides(meta: DeckMeta): Promise<number> {
    const keys = [...(await this.ctx.storage.list<Slide>({ prefix: "slide:" })).keys()];
    if (keys.length > 0) await this.ctx.storage.delete(keys);

    const cleared = meta.count;
    meta.count = 0;
    meta.firstSeq = meta.nextSeq;
    return cleared;
  }
}
```

```ts
  /** Continuous refill: a full window restores the full budget. */
  private refill(meta: DeckMeta, now: number): void {
    const elapsed = now - meta.rateRefilledAt;
    if (elapsed <= 0) return;
    const gained = (elapsed / L.RATE_WINDOW_MS) * L.RATE_LIMIT_PER_MIN;
    meta.rateTokens = Math.min(L.RATE_LIMIT_PER_MIN, meta.rateTokens + gained);
    meta.rateRefilledAt = now;
  }

  /** Seconds until one token is available again, at least 1. */
  private retryAfter(meta: DeckMeta): number {
    const missing = 1 - meta.rateTokens;
    const ms = (missing / L.RATE_LIMIT_PER_MIN) * L.RATE_WINDOW_MS;
    return Math.max(1, Math.ceil(ms / 1000));
  }

  async alarm(): Promise<void> {
    const meta = await this.ctx.storage.get<DeckMeta>(META);
    if (!meta) return;

    const idleFor = Date.now() - meta.lastActiveAt;
    if (idleFor < L.EXPIRY_MS) {
      // Activity happened after this alarm was set; push it out again.
      await this.ctx.storage.setAlarm(meta.lastActiveAt + L.EXPIRY_MS);
      return;
    }

    await this.deleteAllSlides(meta);
    await this.ctx.storage.put(META, meta);
  }
```

```ts
  constructor(ctx: DurableObjectState, env: unknown) {
    super(ctx, env);
    // Keepalive handled by the runtime, so an idle deck stays hibernated.
    this.ctx.setWebSocketAutoResponse(new WebSocketRequestResponsePair("ping", "pong"));
  }

  async fetch(request: Request): Promise<Response> {
    if (request.headers.get("Upgrade") !== "websocket") {
      return new Response("expected websocket upgrade", { status: 426 });
    }
    const meta = await this.ctx.storage.get<DeckMeta>(META);
    if (!meta) return new Response("deck_not_found", { status: 404 });

    const pair = new WebSocketPair();
    const [client, server] = Object.values(pair);

    // acceptWebSocket (not server.accept) is what makes the deck hibernatable.
    this.ctx.acceptWebSocket(server);

    const slides = await this.readSlides();
    server.send(JSON.stringify({
      type: "init",
      slides,
      liveIndex: slides.length - 1,
    } satisfies ServerMessage));

    return new Response(null, { status: 101, webSocket: client });
  }

  /** Viewers never send application messages; ignore anything that arrives. */
  async webSocketMessage(): Promise<void> {}

  async webSocketClose(ws: WebSocket, code: number, reason: string): Promise<void> {
    ws.close(code, reason);
  }

  private broadcast(message: ServerMessage): void {
    const payload = JSON.stringify(message);
    for (const socket of this.ctx.getWebSockets()) {
      try {
        socket.send(payload);
      } catch {
        // A socket that cannot receive is already gone; the runtime cleans it up.
      }
    }
  }
```

```ts
import type { DeckErrorCode } from "./deck-do";

const STATUS: Record<DeckErrorCode | "unauthorized" | "payload_too_large" | "validation_failed", number> = {
  validation_failed: 400,
  unauthorized: 401,
  forbidden: 403,
  deck_not_found: 404,
  payload_too_large: 413,
  rate_limited: 429,
};

export type ErrorCode = keyof typeof STATUS;

export interface ErrorDetail {
  path: string;
  message: string;
}

export function errorResponse(
  code: ErrorCode,
  options: { details?: ErrorDetail[]; retryAfter?: number } = {},
): Response {
  const headers: Record<string, string> = { "Content-Type": "application/json" };
  if (options.retryAfter !== undefined) headers["Retry-After"] = String(options.retryAfter);

  const body: Record<string, unknown> = { error: code };
  if (options.details) body.details = options.details;

  return new Response(JSON.stringify(body), { status: STATUS[code], headers });
}
```

```ts
import { Hono } from "hono";
import { extractBearer, generateApiKey, generateDeckId, hashKey } from "../auth";
import { deckStub } from "../deck-stub";
import { errorResponse, type ErrorDetail } from "../errors";
import { L } from "../limits";
import { SlideInput } from "../schemas";
import type { Env } from "../index";

export const deckRoutes = new Hono<{ Bindings: Env }>();

deckRoutes.post("/decks", async (c) => {
  const deckId = generateDeckId();
  const apiKey = generateApiKey();

  await deckStub(c.env, deckId).init(await hashKey(apiKey));

  const origin = new URL(c.req.url).origin;
  return c.json({
    deck_id: deckId,
    api_key: apiKey,
    view_url: `${origin}/d/${deckId}`,
    mcp_url: `${origin}/mcp/${deckId}`,
    warning: "api_key is shown only once. Store it now.",
  }, 201);
});

/** Pulls the bearer token, or returns the 401 response to send instead. */
function requireKey(header: string | null): string | Response {
  const key = extractBearer(header);
  return key ?? errorResponse("unauthorized");
}

deckRoutes.post("/decks/:deckId/slides", async (c) => {
  const key = requireKey(c.req.header("Authorization") ?? null);
  if (key instanceof Response) return key;

  const declared = Number(c.req.header("Content-Length") ?? 0);
  if (declared > L.BODY_BYTES_MAX) return errorResponse("payload_too_large");

  const raw = await c.req.text();
  if (new TextEncoder().encode(raw).byteLength > L.BODY_BYTES_MAX) {
    return errorResponse("payload_too_large");
  }

  let parsedJson: unknown;
  try {
    parsedJson = JSON.parse(raw);
  } catch {
    return errorResponse("validation_failed", {
      details: [{ path: "", message: "body must be valid JSON" }],
    });
  }

  const parsed = SlideInput.safeParse(parsedJson);
  if (!parsed.success) {
    const details: ErrorDetail[] = parsed.error.issues.map((issue) => ({
      path: issue.path.join("."),
      message: issue.message,
    }));
    return errorResponse("validation_failed", { details });
  }

  const result = await deckStub(c.env, c.req.param("deckId")).pushSlide(key, parsed.data);
  if (!result.ok) return errorResponse(result.error, { retryAfter: result.retryAfter });

  return c.json(result.value, 201);
});

deckRoutes.get("/decks/:deckId/slides", async (c) => {
  const key = requireKey(c.req.header("Authorization") ?? null);
  if (key instanceof Response) return key;

  const result = await deckStub(c.env, c.req.param("deckId")).listSlides(key);
  if (!result.ok) return errorResponse(result.error);
  return c.json(result.value);
});

deckRoutes.delete("/decks/:deckId/slides", async (c) => {
  const key = requireKey(c.req.header("Authorization") ?? null);
  if (key instanceof Response) return key;

  const result = await deckStub(c.env, c.req.param("deckId")).clearSlides(key);
  if (!result.ok) return errorResponse(result.error);
  return c.json(result.value);
});
```

```ts
import { Hono } from "hono";
import { extractBearer } from "../auth";
import { deckStub } from "../deck-stub";
import { errorResponse } from "../errors";
import { TOOL_DEFINITIONS } from "../mcp-schemas";
import { SlideInput } from "../schemas";
import type { Env } from "../index";

const DEFAULT_PROTOCOL_VERSION = "2025-06-18";
const SERVER_INFO = { name: "j2slide", version: "1.0.0" };

interface JsonRpcRequest {
  jsonrpc: "2.0";
  id?: string | number | null;
  method: string;
  params?: Record<string, unknown>;
}

const result = (id: unknown, value: unknown) =>
  Response.json({ jsonrpc: "2.0", id, result: value });

const rpcError = (id: unknown, code: number, message: string) =>
  Response.json({ jsonrpc: "2.0", id, error: { code, message } });

/** A tool failure is reported inside the result, so the model can read and retry. */
const toolText = (text: string, isError = false) => ({
  content: [{ type: "text", text }],
  ...(isError ? { isError: true } : {}),
});

export const mcpRoutes = new Hono<{ Bindings: Env }>();

mcpRoutes.post("/mcp/:deckId", async (c) => {
  const apiKey = extractBearer(c.req.header("Authorization") ?? null);
  if (!apiKey) return errorResponse("unauthorized");

  let request: JsonRpcRequest;
  try {
    request = await c.req.json();
  } catch {
    return rpcError(null, -32700, "Parse error");
  }

  const id = request.id ?? null;
  const stub = deckStub(c.env, c.req.param("deckId"));

  switch (request.method) {
    case "initialize": {
      const requested = request.params?.protocolVersion;
      return result(id, {
        // Echo the client's version so a newer client is not turned away.
        protocolVersion: typeof requested === "string" ? requested : DEFAULT_PROTOCOL_VERSION,
        capabilities: { tools: {} },
        serverInfo: SERVER_INFO,
      });
    }

    case "notifications/initialized":
      return new Response(null, { status: 202 });

    case "ping":
      return result(id, {});

    case "tools/list":
      return result(id, {
        tools: TOOL_DEFINITIONS.map(({ name, description, inputSchema }) => ({
          name, description, inputSchema,
        })),
      });

    case "tools/call": {
      const name = request.params?.name;
      const args = (request.params?.arguments ?? {}) as Record<string, unknown>;
      const tool = TOOL_DEFINITIONS.find((t) => t.name === name);
      if (!tool) return result(id, toolText(`Unknown tool: ${String(name)}`, true));

      if (tool.slideType === null) {
        const cleared = await stub.clearSlides(apiKey);
        if (!cleared.ok) return result(id, toolText(`Cannot clear deck: ${cleared.error}`, true));
        return result(id, toolText(`Cleared ${cleared.value.cleared} slide(s). The deck is now empty.`));
      }

      const parsed = SlideInput.safeParse({ ...args, type: tool.slideType });
      if (!parsed.success) {
        const problems = parsed.error.issues
          .map((issue) => `${issue.path.join(".") || "(root)"}: ${issue.message}`)
          .join("; ");
        return result(id, toolText(`Invalid arguments — ${problems}`, true));
      }

      const pushed = await stub.pushSlide(apiKey, parsed.data);
      if (!pushed.ok) {
        const suffix = pushed.retryAfter ? ` Retry in ${pushed.retryAfter}s.` : "";
        return result(id, toolText(`Cannot show slide: ${pushed.error}.${suffix}`, true));
      }

      return result(id, toolText(
        `Now showing "${parsed.data.title}" as slide ${pushed.value.index + 1} of ${pushed.value.total}.`,
      ));
    }

    default:
      return rpcError(id, -32601, `Method not found: ${request.method}`);
  }
});

/** No server-initiated streaming, so the GET half of Streamable HTTP is refused. */
mcpRoutes.get("/mcp/:deckId", (c) => c.text("Method Not Allowed", 405));
```

```js
/**
 * Pure slide renderers. Every function takes data and returns an SVG string —
 * no DOM, no globals, no side effects. That is what makes them testable.
 */

export const CANVAS = { w: 1600, h: 900, pad: 64 };

const TITLE_Y = 128;
const RULE_Y = 152;
const CONTENT_TOP = 210;
const CONTENT_BOTTOM = 800;
const FOOTER_Y = 852;
const ROTATE_LABELS_ABOVE = 8;

function esc(value) {
  return String(value)
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&#39;");
}

/** Rounds to 2dp and never emits NaN, which would silently break the SVG. */
function n(value) {
  return Number.isFinite(value) ? Math.round(value * 100) / 100 : 0;
}

function text(content, x, y, opts = {}) {
  const attrs = [
    `x="${n(x)}"`,
    `y="${n(y)}"`,
    `font-size="${opts.size ?? 24}"`,
    `fill="${opts.fill ?? "#000"}"`,
    `font-family="${opts.family ?? ""}"`,
    opts.weight ? `font-weight="${opts.weight}"` : "",
    opts.anchor ? `text-anchor="${opts.anchor}"` : "",
    opts.baseline ? `dominant-baseline="${opts.baseline}"` : "",
    opts.className ? `class="${opts.className}"` : "",
    opts.transform ? `transform="${opts.transform}"` : "",
  ].filter(Boolean).join(" ");
  return `<text ${attrs}>${esc(content)}</text>`;
}

function frame(slide, theme, body, footer) {
  return [
    `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 ${CANVAS.w} ${CANVAS.h}" width="100%" height="100%">`,
    `<rect x="0" y="0" width="${CANVAS.w}" height="${CANVAS.h}" fill="${theme.bg}"/>`,
    text(slide.title, CANVAS.pad, TITLE_Y, {
      size: theme.titleSize, fill: theme.fg, family: theme.fontFamily,
      weight: "700", className: "slide-title",
    }),
    `<rect x="${CANVAS.pad}" y="${RULE_Y}" width="96" height="4" fill="${theme.accent}"/>`,
    body,
    footer ?? "",
    `</svg>`,
  ].join("\n");
}

function footerText(theme, left, right) {
  return [
    text(left, CANVAS.pad, FOOTER_Y, {
      size: theme.footerSize, fill: theme.muted, family: theme.fontFamily, className: "footer-left",
    }),
    text(right, CANVAS.w - CANVAS.pad, FOOTER_Y, {
      size: theme.footerSize, fill: theme.muted, family: theme.fontFamily,
      anchor: "end", className: "footer-right",
    }),
  ].join("\n");
}

function formatValue(value, unit) {
  const rounded = Math.round(value * 100) / 100;
  return unit ? `${rounded} ${unit}` : String(rounded);
}

function renderBar(slide, theme) {
  const data = slide.data;
  const left = CANVAS.pad + 16;
  const right = CANVAS.w - CANVAS.pad;
  const width = right - left;
  const baseline = CONTENT_BOTTOM - 60;
  const top = CONTENT_TOP + 40;

  const values = data.map((d) => d.value);
  const max = Math.max(0, ...values);
  const min = Math.min(0, ...values);
  const span = max - min || 1;
  const zeroY = baseline - ((0 - min) / span) * (baseline - top);

  const slot = width / data.length;
  const barWidth = Math.min(120, slot * 0.6);
  const rotate = data.length > ROTATE_LABELS_ABOVE;

  const parts = [`<line x1="${left}" y1="${n(zeroY)}" x2="${right}" y2="${n(zeroY)}" stroke="${theme.grid}" stroke-width="2"/>`];

  data.forEach((point, i) => {
    const centre = left + slot * (i + 0.5);
    const valueY = baseline - ((point.value - min) / span) * (baseline - top);
    const y = Math.min(zeroY, valueY);
    const height = Math.abs(zeroY - valueY);
    const colour = theme.series[i % theme.series.length];

    parts.push(
      `<rect class="bar" x="${n(centre - barWidth / 2)}" y="${n(y)}" width="${n(barWidth)}" height="${n(height)}" rx="6" fill="${colour}"/>`,
    );
    parts.push(text(formatValue(point.value, slide.unit), centre, y - 14, {
      size: theme.valueSize, fill: theme.fg, family: theme.fontFamily, anchor: "middle", className: "bar-value",
    }));
    parts.push(text(point.label, centre, baseline + 40, {
      size: theme.labelSize, fill: theme.muted, family: theme.fontFamily,
      anchor: rotate ? "end" : "middle", className: "bar-label",
      transform: rotate ? `rotate(-45 ${n(centre)} ${n(baseline + 40)})` : undefined,
    }));
  });

  return parts.join("\n");
}

function renderLine(slide, theme) {
  const data = slide.data;
  const left = CANVAS.pad + 80;
  const right = CANVAS.w - CANVAS.pad;
  const baseline = CONTENT_BOTTOM - 60;
  const top = CONTENT_TOP + 40;

  const values = data.map((d) => d.value);
  const max = Math.max(...values);
  const min = Math.min(...values);
  const span = max - min || 1;
  const step = data.length > 1 ? (right - left) / (data.length - 1) : 0;
  const at = (i, value) => ({
    x: data.length > 1 ? left + step * i : (left + right) / 2,
    y: baseline - ((value - min) / span) * (baseline - top),
  });

  const parts = [];
  for (const fraction of [0, 0.5, 1]) {
    const y = baseline - fraction * (baseline - top);
    parts.push(`<line x1="${left}" y1="${n(y)}" x2="${right}" y2="${n(y)}" stroke="${theme.grid}" stroke-width="2"/>`);
    parts.push(text(formatValue(min + fraction * span, slide.unit), left - 16, y + 8, {
      size: theme.labelSize, fill: theme.muted, family: theme.fontFamily, anchor: "end", className: "axis-label",
    }));
  }

  const points = data.map((d, i) => at(i, d.value));
  parts.push(
    `<polyline fill="none" stroke="${theme.series[0]}" stroke-width="5" stroke-linejoin="round" points="${points.map((p) => `${n(p.x)},${n(p.y)}`).join(" ")}"/>`,
  );

  points.forEach((p, i) => {
    parts.push(`<circle class="point" cx="${n(p.x)}" cy="${n(p.y)}" r="8" fill="${theme.series[0]}"/>`);
    parts.push(text(data[i].label, p.x, baseline + 40, {
      size: theme.labelSize, fill: theme.muted, family: theme.fontFamily,
      anchor: data.length > ROTATE_LABELS_ABOVE ? "end" : "middle", className: "line-label",
      transform: data.length > ROTATE_LABELS_ABOVE ? `rotate(-45 ${n(p.x)} ${n(baseline + 40)})` : undefined,
    }));
  });

  return parts.join("\n");
}

function renderPie(slide, theme) {
  const data = slide.data;
  const cx = 480;
  const cy = (CONTENT_TOP + CONTENT_BOTTOM) / 2;
  const outer = 240;
  const inner = 130;

  const total = data.reduce((sum, d) => sum + d.value, 0);
  const parts = [];

  if (total <= 0) {
    // Nothing to divide: draw an empty ring rather than emitting NaN paths.
    parts.push(`<circle cx="${cx}" cy="${n(cy)}" r="${outer}" fill="none" stroke="${theme.grid}" stroke-width="${outer - inner}"/>`);
  } else if (data.length === 1) {
    parts.push(`<circle class="slice" cx="${cx}" cy="${n(cy)}" r="${(outer + inner) / 2}" fill="none" stroke="${theme.series[0]}" stroke-width="${outer - inner}"/>`);
  } else {
    let angle = -Math.PI / 2;
    data.forEach((slice, i) => {
      const sweep = (slice.value / total) * Math.PI * 2;
      const end = angle + sweep;
      const large = sweep > Math.PI ? 1 : 0;
      const p = (radius, a) => `${n(cx + radius * Math.cos(a))} ${n(cy + radius * Math.sin(a))}`;

      parts.push(
        `<path class="slice" d="M ${p(outer, angle)} A ${outer} ${outer} 0 ${large} 1 ${p(outer, end)} L ${p(inner, end)} A ${inner} ${inner} 0 ${large} 0 ${p(inner, angle)} Z" fill="${theme.series[i % theme.series.length]}"/>`,
      );
      angle = end;
    });
  }

  const legendX = 860;
  const legendTop = cy - (data.length * 56) / 2 + 28;
  data.forEach((slice, i) => {
    const y = legendTop + i * 56;
    const percent = total > 0 ? Math.round((slice.value / total) * 100) : 0;
    parts.push(`<rect x="${legendX}" y="${n(y - 18)}" width="24" height="24" rx="5" fill="${theme.series[i % theme.series.length]}"/>`);
    parts.push(text(slice.label, legendX + 40, y, {
      size: 28, fill: theme.fg, family: theme.fontFamily, className: "legend-label",
    }));
    parts.push(text(`${formatValue(slice.value)} · ${percent}%`, CANVAS.w - CANVAS.pad, y, {
      size: 28, fill: theme.muted, family: theme.fontFamily, anchor: "end", className: "legend-value",
    }));
  });

  return parts.join("\n");
}

function renderText(slide, theme) {
  const count = slide.bullets.length;
  // Interpolate down from the max size as the list fills up.
  const size = count <= 1
    ? theme.bulletMaxSize
    : theme.bulletMaxSize - ((theme.bulletMaxSize - theme.bulletMinSize) * (count - 1)) / 7;
  const gap = (CONTENT_BOTTOM - CONTENT_TOP) / (count + 1);

  return slide.bullets.map((bullet, i) => {
    const y = CONTENT_TOP + gap * (i + 1);
    return [
      `<circle cx="${CANVAS.pad + 12}" cy="${n(y - 10)}" r="7" fill="${theme.accent}"/>`,
      text(bullet, CANVAS.pad + 44, y, {
        size: n(size), fill: theme.fg, family: theme.fontFamily, className: "bullet",
      }),
    ].join("\n");
  }).join("\n");
}

function renderKpi(slide, theme) {
  const items = slide.items;
  const left = CANVAS.pad;
  const width = CANVAS.w - CANVAS.pad * 2;
  const gap = 32;
  const tileWidth = (width - gap * (items.length - 1)) / items.length;
  const tileTop = CONTENT_TOP + 40;
  const tileHeight = 400;

  return items.map((item, i) => {
    const x = left + (tileWidth + gap) * i;
    const centre = x + tileWidth / 2;
    const arrow = item.trend === "up" ? "▲" : item.trend === "down" ? "▼" : "";
    const colour = item.trend === "up" ? theme.up : item.trend === "down" ? theme.down : theme.muted;

    const parts = [
      `<rect class="kpi-tile" x="${n(x)}" y="${tileTop}" width="${n(tileWidth)}" height="${tileHeight}" rx="18" fill="${theme.grid}"/>`,
      text(item.value, centre, tileTop + 200, {
        size: theme.kpiValueSize, fill: theme.fg, family: theme.fontFamily,
        weight: "700", anchor: "middle", className: "kpi-value",
      }),
      text(item.label, centre, tileTop + 264, {
        size: 28, fill: theme.muted, family: theme.fontFamily, anchor: "middle", className: "kpi-label",
      }),
    ];

    if (item.delta) {
      parts.push(text(`${arrow} ${item.delta}`.trim(), centre, tileTop + 330, {
        size: 32, fill: colour, family: theme.fontFamily, anchor: "middle", className: "kpi-delta",
      }));
    }

    return parts.join("\n");
  }).join("\n");
}

const RENDERERS = {
  bar: renderBar,
  line: renderLine,
  pie: renderPie,
  text: renderText,
  kpi: renderKpi,
};

/**
 * @param {object} slide  a validated slide
 * @param {object} theme  one of THEMES.dark / THEMES.light
 * @param {object} [position] optional `{ index, total, live }` for the footer
 * @returns {string} a complete SVG document
 */
export function renderSlide(slide, theme, position) {
  const renderer = RENDERERS[slide.type];
  if (!renderer) {
    return frame({ title: "Unsupported slide" }, theme, text(
      `No renderer for type "${slide.type}"`, CANVAS.pad, 420,
      { size: 32, fill: theme.muted, family: theme.fontFamily },
    ), "");
  }

  const footer = position
    ? footerText(theme, position.live ? "● live" : "○ reconnecting", `${position.index + 1} / ${position.total}`)
    : "";

  return frame(slide, theme, renderer(slide, theme), footer);
}

/** Shown before the first slide arrives, so a presenter can confirm the link. */
export function renderStandby(deckId, theme) {
  return frame({ title: "Waiting for the first slide" }, theme, [
    text(`Deck ${deckId}`, CANVAS.pad, 340, {
      size: 32, fill: theme.muted, family: theme.fontFamily, className: "standby-deck",
    }),
    text("Slides pushed to this deck will appear here immediately.", CANVAS.pad, 400, {
      size: 28, fill: theme.muted, family: theme.fontFamily,
    }),
  ].join("\n"), "");
}
```

```js
import { renderSlide, renderStandby } from "./render.js";
import { THEMES } from "./theme.js";

const deckId = document.body.dataset.deckId;
const stage = document.getElementById("stage");
const jump = document.getElementById("jump");

const state = {
  slides: [],
  index: -1,
  /** True while the viewer is pinned to the newest slide. */
  following: true,
  live: false,
  theme: THEMES[localStorage.getItem("j2slide-theme") === "light" ? "light" : "dark"],
};

function draw() {
  if (state.slides.length === 0) {
    stage.innerHTML = `<div class="slide">${renderStandby(deckId, state.theme)}</div>`;
    jump.hidden = true;
    return;
  }

  const slide = state.slides[state.index];
  stage.innerHTML = `<div class="slide">${renderSlide(slide, state.theme, {
    index: state.index,
    total: state.slides.length,
    live: state.live,
  })}</div>`;

  const behind = state.slides.length - 1 - state.index;
  jump.hidden = behind <= 0;
  jump.textContent = behind === 1 ? "▼ 1 new slide" : `▼ ${behind} new slides`;
}

function goTo(index) {
  state.index = Math.max(0, Math.min(state.slides.length - 1, index));
  state.following = state.index === state.slides.length - 1;
  draw();
}

function connect(attempt = 0) {
  const protocol = location.protocol === "https:" ? "wss:" : "ws:";
  const socket = new WebSocket(`${protocol}//${location.host}/d/${deckId}/ws`);

  socket.addEventListener("open", () => {
    state.live = true;
    attempt = 0;
    // Keeps the connection warm without waking the Durable Object.
    socket.pingTimer = setInterval(() => socket.send("ping"), 30_000);
  });

  socket.addEventListener("message", (event) => {
    const message = JSON.parse(event.data);

    if (message.type === "init") {
      state.slides = message.slides;
      state.index = message.liveIndex;
      state.following = true;
    } else if (message.type === "slide") {
      state.slides.push(message.slide);
      // Only follow if the viewer had not navigated away.
      if (state.following) state.index = state.slides.length - 1;
    } else if (message.type === "clear") {
      state.slides = [];
      state.index = -1;
      state.following = true;
    }
    draw();
  });

  const reconnect = () => {
    clearInterval(socket.pingTimer);
    state.live = false;
    draw();
    const delay = Math.min(15_000, 1000 * 2 ** attempt);
    setTimeout(() => connect(attempt + 1), delay);
  };

  socket.addEventListener("close", reconnect);
  socket.addEventListener("error", () => socket.close());
}

jump.addEventListener("click", () => goTo(state.slides.length - 1));

document.addEventListener("keydown", (event) => {
  switch (event.key) {
    case "ArrowLeft":
      goTo(state.index - 1);
      break;
    case "ArrowRight":
    case " ":
      event.preventDefault();
      goTo(state.index + 1);
      break;
    case "End":
      goTo(state.slides.length - 1);
      break;
    case "f":
    case "F":
      if (document.fullscreenElement) document.exitFullscreen();
      else document.documentElement.requestFullscreen();
      break;
    case "t":
    case "T": {
      const next = state.theme.name === "dark" ? "light" : "dark";
      state.theme = THEMES[next];
      localStorage.setItem("j2slide-theme", next);
      draw();
      break;
    }
```

````markdown
# j2slide

Push chart JSON over HTTP; the slide appears immediately on every open viewer.

Built for AI agents: while the agent talks, it calls a presentation tool and the
audience sees the supporting chart on a shared screen.

## How it works

1. `POST /decks` returns an `api_key` (secret, for the agent) and a `deck_id`
   (public, for the audience).
2. Share `https://<host>/d/<deck_id>`. Anyone with the link can watch; nobody
   with the link can write.
3. The agent pushes slides with the `api_key`. Every open viewer updates at once.

The `api_key` is shown exactly once. Only its SHA-256 digest is stored.

## Slide types

`bar`, `line`, `pie`, `text`, `kpi`. Each has hard size limits so the fixed
16:9 frame cannot be broken by input — see `/docs` for the exact bounds.

## Quick start

```bash
npm install
npm run dev
```

```bash
# Create a deck
curl -s -X POST http://localhost:8787/decks

# Push a slide
curl -s -X POST http://localhost:8787/decks/<deck_id>/slides \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  -d '{"type":"bar","title":"Revenue by quarter","unit":"M USD",
       "data":[{"label":"Q1","value":12.4},{"label":"Q2","value":15.1}]}'

# Start a new session
curl -s -X DELETE http://localhost:8787/decks/<deck_id>/slides \
  -H "Authorization: Bearer <api_key>"
```

Open `http://localhost:8787/d/<deck_id>` to watch.

## Connecting an agent

**OpenAPI** — point any agent framework at `/openapi.json`. Every limit is
published in the schema, so the model sees the constraints before it calls.

**MCP** — add the server as Streamable HTTP:

```json
{
  "mcpServers": {
    "j2slide": {
      "url": "https://<host>/mcp/<deck_id>",
      "headers": { "Authorization": "Bearer <api_key>" }
    }
  }
}
```

Tools: `present_bar`, `present_line`, `present_pie`, `present_text`,
`present_kpi`, `clear_deck`.

## Viewer controls

| Key | Action |
|---|---|
| `←` `→` `Space` | previous / next slide |
| `End` | jump to the live slide |
| `F` | fullscreen |
| `T` | toggle dark/light |

A new slide auto-advances the viewer only if they are already on the last
slide. If they have navigated back, a `▼ n new slides` badge appears instead.

## Limits

- 60 slides per minute per deck
- 200 slides per deck; the oldest is evicted beyond that
- 32 KB per request
- Slides are deleted after 7 days of inactivity; the deck and its key survive
````
